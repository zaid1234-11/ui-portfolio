01 FinTrac AI — Financial Decision Operating System
Next.js 14 TypeScript Tailwind CSS Framer Motion Radix UI
Beat 1 • The Problem
Personal budgeting applications typically function as passive historical spreadsheets, displaying past transactions without answering: “If I change a habit today, how does that impact my long-term goals?” When recommending budget cuts, apps enforce equal, rigid percentage reductions across every category, ignoring behavioral friction—cutting groceries creates high daily fatigue, while cutting unused subscriptions creates almost none. The challenge was building an interface that models spending friction, explains recommendations transparently, and lets users simulate trade-offs in seconds.
Beat 2 • What I Did
  • Liquid Glass Design System: Engineered translucent surfaces using layered CSS backdrop-filter blur and semantic elevation tokens, limiting composite layers to ensure smooth mobile rendering.
  • Future Simulator: Built an interactive slider using Radix UI and Framer Motion that recalculates and animates projected goal dates in real time upon dragging.
  • Prioritization Engine & Explainability: Wrote deterministic client ranking rules to surface exactly one high-impact Hero Action at the top, paired with a mandatory “Why am I seeing this?” transparent breakdown on every automated insight.
  • AI Review & Edit: Used AI to scaffold state permutations, but rejected multi-tiered AI cards in favor of hand-coded deterministic priority logic and concise plain-language projections.
Beat 3 • What Came of It
Reduced the user journey from opening the app to taking a concrete financial decision from several minutes down to under 10 seconds. Standardized the Liquid Glass design tokens across desktop and mobile, and achieved a 98/100 Lighthouse Accessibility score with zero contrast issues or focus traps.
02 RetroLab — Real-Time Browser Pixel, Dither & CRT Shader Lab
React 19 TypeScript Canvas 2D API Uint8ClampedArray Framer Motion
Beat 1 • The Problem
Creating authentic retro aesthetics (Floyd-Steinberg dithering, Voronoi cellular quantization, halftone dot matrix, Sobel CRT scanlines) usually requires heavy desktop tools like Photoshop or slow server-side processing pipelines. This adds latency to creative experimentation and forces users to upload personal images to remote servers. The goal was building a 100% client-side graphics lab executing shader algorithms with zero network latency.
Beat 2 • What I Did
  • Direct Buffer Manipulation: Handled all pixel math directly on 1D Uint8ClampedArray typed arrays (ImageData) to bypass DOM/SVG overhead.
  • In-Place Buffer Mutation: Modified existing pixel buffers in-place during recalculation rather than creating new objects, eliminating garbage collection frame drops during continuous slider adjustments.
  • Dual-Resolution Pipeline: Downsamples previews during active slider drags for sub-16ms feedback, rendering full resolution upon release. Implemented custom 1x–8x nearest-neighbor scaling for pixel-crisp exports.
  • AI Review & Edit: AI-generated kernel loops used nested arrays that froze the main thread on >1200px images; I refactored the algorithms into flat 1D indexed iterations with strict memory bounds.
Beat 3 • What Came of It
Delivered a production browser application running at a sustained 60 FPS with sub-16ms preview feedback across all four algorithm pipelines, achieving 100% client privacy with 0% server compute load.

03 SalesSphere — 100K+ Record Enterprise Analytics Dashboard
React 19 TypeScript Tailwind v4 TanStack Virtual Zustand Recharts
Beat 1 • The Problem
Enterprise sales operators frequently analyze datasets exceeding 100,000 transaction records. Rendering massive un-virtualized tables alongside dynamic charts causes browser DOM bloat, jank, and frozen tabs during multi-column filtering. The challenge was building an interface supporting real-time data slicing while sustaining 60 FPS.
Beat 2 • What I Did
  • 5-Layer Architecture: Decoupled data handling from views (Repository → Transformation → Analytics → Decision → Presentation) to avoid redundant chart recalculations.
  • Virtual List Rendering: Integrated TanStack Virtual to render only active viewport table rows, paired with centralized Zustand stores for instantaneous multi-column filtering and CSV exports.
  • AI Review & Edit: Rejected an AI-generated speculative “AI command center” in favor of a clean, business-first analytics layout inspired by Stripe Analytics and Power BI.
Beat 3 • What Came of It
Sustained 60 FPS table scrolling across 100K+ records with a compact 285KB JavaScript bundle, achieving a 95+ Lighthouse score and WCAG 2.1 AA compliant color contrast.
04 ARTEFACT — Interactive Digital Atelier Portfolio System
React 19 Vite Three.js / GLSL Framer Motion Web Audio
Beat 1 • The Problem
Most digital portfolios are static resume grids that describe craft in bullet points rather than demonstrating it through live interaction. The goal was translating the physical tactility of an architect’s atelier into a 120 FPS web experience with zero scroll-jacking and full accessibility.
Beat 2 • What I Did
  • Tactile Vinyl & Audio Engine: Engineered a 33⅓ RPM vinyl player with Web Audio API sync, dynamic tonearm physics, and damped spring sleeve retraction.
  • Kinetic Proximity & GLSL Shaders: Built spatial variable typography calculating Euclidean pointer distance to font axes ('wght' 300→900) and a zero-re-render GLSL noise scroll dissolve.
  • AI Review & Edit: Caught and fixed an AI canvas bug that clipped confetti on mobile resize by binding width to parent element dimensions and adding RAF cleanup hooks.
Beat 3 • What Came of It
Achieved native 120Hz momentum scrolling on mobile (touch-action: pan-y pinch-zoom), zero layout shift, and WCAG 2.1 AA compliance across all interactive forms.
