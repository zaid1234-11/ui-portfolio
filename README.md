## About

**ARTEFACT** is my personal portfolio built around the concept of a physical studio journal. It pairs tactile scrapbook textures (cardstock, brass clips, paper grain, washi tape, and rubber stamps) with modern frontend engineering, smooth animations, and interactive components.

- **Design**: Physical stationery meets digital editorial design
- **Performance**: 60FPS animations, Lenis smooth scrolling, and full responsive support
- **Themes**: Warm vintage cream by default, with an obsidian dark mode toggle

---

## Features

- **Atelier Boot Preloader**: Paced progress counter with animated typography and smooth curtain reveal
- **Cabinet Archive (Projects)**: Overlapping interactive file folders with custom washi tape labels, brass clips, and project specs
- **Methodology (Process)**: Sticky 4-step sequence inside a custom CRT TV monitor frame
- **Image Reveal (About)**: Scroll-driven black-and-white to full color unroll with sequenced bio details
- **Smooth Navigation**: Global floating navbar that automatically hides during the About section to maximize focus

## Getting Started

### Prerequisites
- Node.js (v18+)
- npm or pnpm

### Setup

```bash
# Clone the repository
git clone https://github.com/zaid1234-11/ui-portfolio.git

# Install dependencies
npm install

# Start local dev server
npm run dev
```

### Build

```bash
# Production build
npm run build

# Preview build
npm run preview
```
